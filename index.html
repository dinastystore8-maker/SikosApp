Memilih Potret/Lanskap akan otomatis membuka layar penuh (fullscreen) lalu mengunci orientasi — ini caranya browser HP mengizinkan penguncian di luar app yang di-install. Kalau tombol tidak bergerak, coba matikan dulu rotasi otomatis bawaan HP dari menu Pengaturan Cepat, lalu pilih lagi di sini. Sebagian browser (misalnya Safari iPhone) memang belum mendukung fitur ini sama sekali.

Template Kwitansi

Tulis format kwitansi sesuai kebutuhan. Gunakan kode di bawah ini, akan otomatis terisi datanya saat kwitansi dicetak dari transaksi Kas Sewa (cash):

{nomor} {tanggal} {nama_penyewa} {kamar} {periode} {tipe_periode} {jumlah} {terbilang} {metode} {nama_kos} {alamat_kos}
Sinkronisasi Cloud

Aplikasi ini berjalan 100% di HP/browser kamu (tanpa server), jadi belum ada sinkronisasi otomatis antar perangkat. Cara paling praktis sekarang:

  1. Buka Database / Backup → Export Backup secara rutin (mingguan/bulanan).
  2. Simpan file backup itu ke Google Drive / cloud storage pilihanmu.
  3. Di HP/perangkat lain, buka app ini → Import Backup → pilih file tadi.

Sinkronisasi real-time otomatis antar banyak perangkat butuh server/database online (misalnya Firebase atau Supabase) — ini pengembangan besar di luar app 1-file ini. Kalau kamu mau, ini bisa jadi proyek lanjutan terpisah.

Penyimpanan Foto Kamar

Foto kamar sekarang disimpan di IndexedDB (bukan localStorage), sehingga kapasitasnya jauh lebih besar — cukup untuk banyak foto asli beresolusi tinggi per kamar. Foto otomatis dipadatkan (resize + kompres) saat diunggah supaya tetap ringan tanpa mengurangi kualitas secara signifikan.
